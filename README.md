# Beatrix Website

The Beatrix website is a Next.js Pages Router application for Health Coach
Abby. It contains the public marketing pages, a locally authored blog, contact
and health assessment forms, and static image assets.

## Run locally

Requirements: Node.js 18.18 or newer (Node.js 20 LTS recommended) and npm.

```bash
npm ci
npm run dev
```

Open [http://localhost:3000](http://localhost:3000). Other project commands:

```bash
npm run build
npm start
npm run lint
```

See [HANDOVER.md](./HANDOVER.md) for the architecture, route and content
inventory, brand assets, FAQ copy, CMS direction, form behavior, deployment
notes, security status, and prioritized handover actions. The owner-facing
overview is in [OWNER_PROJECT_SUMMARY.docx](./OWNER_PROJECT_SUMMARY.docx).
